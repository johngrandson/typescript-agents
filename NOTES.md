# Notas do workspace

- João mantém o TypeScript Starter Harness, um repositório de ferramentas de
  desenvolvimento separado da aplicação de referência `typescript_starter`.
- O plugin canônico atende TypeScript, Fastify, TypeBox, Next.js, React, Expo,
  React Native, Drizzle e PostgreSQL.
- Claude Code usa o plugin canônico. Amp, Codex, Pi, OpenCode e dsh recebem
  distribuições geradas a partir dele.
- A preparação para o GitHub deve terminar localmente, sem push.
- As contribuições usam commits semânticos e funcionais, com os checks ativos.
- Inventário e cobertura ficam em `docs/quality`; os dados da aplicação de
  referência ficam em `docs/reference`. Os avisos de copyright ficam em `LICENSE`.
- As especificações de workflows ficam localmente em `workflows/*.md`.
- João é o mantenedor de todos os plugins, incluindo o opcional `catchup`,
  que mantém sua funcionalidade e versão independente.
