# Runtime evidence

Record environment, checkout, command/tool, timestamp, expected/observed output and limits. Health proves liveness; it does not prove migrations, domain mutation or worker processing.

Test a Session creation/read only on an isolated instance, then inspect both event transport and persistence behavior needed by the change. Browser evidence cannot establish mobile
native rendering. Clean up only resources created for the probe.

## Starter evidence

Read `apps/e2e/support` in the application checkout. Use the captured starter snapshot recorded by the harness for copied examples; confirm changed source hashes before adapting them.
