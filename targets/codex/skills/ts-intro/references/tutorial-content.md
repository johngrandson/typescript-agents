# Six-section tutorial

## 1. What the harness offers

The typescript-starter plugin provides 51 skills and 26 agent roles across the starter's contracts, API, database, web, mobile, worker and verification boundaries. Forty skills are
public; eleven supply knowledge automatically. Hook enforcement differs by agent runtime and must be checked separately from guidance.

## 2. Pick a workflow

Use $typescript-starter:ts-brainstorm for vague requirements, $typescript-starter:ts-plan to create a coordinated plan, $typescript-starter:ts-work to execute an existing plan,
$typescript-starter:ts-quick for a small edit and $typescript-starter:ts-full for the authorized
complete cycle. A plan and review are artifacts; each workflow retains its transition boundaries and existing session authorization.

## 3. Investigate and verify

$typescript-starter:ts-investigate reproduces and traces causes; $typescript-starter:ts-trace maps callers; $typescript-starter:ts-verify discovers actual pnpm/Turbo scripts. SQL needs disposable
Postgres coverage, browser behavior uses
Playwright and native rendering needs separate evidence. Runtime inspection uses available HTTP/OpenAPI/log/SQL/UI tools; no app MCP is installed.

## 4. Understand the stack

TypeBox schemas and derived DTOs live in packages/types. Services, thin Fastify routes, AppContext and repository ports are intended. Web Server Actions/SSE and mobile
REST/WS/loading hooks differ. The job runner is sequential with fenced leases and at-least-once effects. clientId is not authenticated identity; the event bus is per API instance.

## 5. Review and dependencies

$typescript-starter:ts-review reports read-only findings with requirements coverage. $typescript-starter:ts-triage selects findings, $typescript-starter:ts-pr-review handles authorized PR feedback and
$typescript-starter:ts-watch-pr watches event deltas.
$typescript-starter:ts-codex-loop bounds local CLI review rounds. Dependency audit/update/vet use pnpm lock identities, integrity and exact reviewed evidence; no model service is required by the
local gate.

## 6. Retain knowledge and customize

$typescript-starter:ts-compound captures a verified solution, $typescript-starter:ts-learn-from-fix saves a short rule, $typescript-starter:ts-recall searches history and $typescript-starter:ts-init
manages project guidance without overwriting unrelated
rules. $typescript-starter:ts-freeze scopes edits according to runtime support; $typescript-starter:ts-permissions proposes narrow command permissions. End with the appropriate next workflow, not an
automatic
installation or publication.
