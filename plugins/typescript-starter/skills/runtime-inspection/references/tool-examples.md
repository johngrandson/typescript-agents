# Available inspection paths

Inspect /modules and read app.ts for the registered OpenAPI path. Use existing Fastify injection tests, local HTTP, structured logs and bounded SQL as separate evidence. The
starter ships no application-inspection MCP server.

Use a connected browser tool only when available. Do not claim remote evaluation, module docs or process introspection from a fabricated tool name. Match dependency docs to
pnpm-lock.yaml through /ts:docs-fetcher.
