# Changelog

Changes to the TypeScript Starter Harness.

This checkout has no published release. The current TypeScript starter version
is `1.0.0`; the optional `catchup` plugin remains at `0.1.0`.

## [Unreleased]

### Changed

- Present the TypeScript Starter Harness as an independent local distribution.
- Organize current inventory, coverage, verification and reference records under
  `docs/quality` and `docs/reference`.
- Rename internal helpers and regression groups around their current harness and
  dependency responsibilities.

### Added

- 51 skills, 26 agents and 23 hook responsibilities for Node, TypeScript,
  Fastify, TypeBox, Next.js, React, Expo, React Native, Drizzle and PostgreSQL.
- Main plugin `typescript-starter`, Claude namespace `ts`, and compatibility
  commands through `drizzle` and `react`.
- Generated Amp, Codex, Pi, OpenCode and dsh distributions with runtime-specific
  workflows, packaged resources and executable scripts.
- Dependency inspection for pnpm lockfile v9, registry metadata, package
  integrity, archive extraction and TypeScript syntax. Review decisions use an
  explicit ledger; updates audit the prepared lock before installation.
- pnpm and Lefthook contributor tooling, Python and Bash tests, snapshot checks
  and local acceptance records.

See [installation](README.md) and [runtime support](docs/runtime-support.md)
for the current commands and capability limits.
